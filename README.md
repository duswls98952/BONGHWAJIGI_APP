# 봉화지기

재난 정보를 확인하고 상황에 맞는 안내를 받기 위한 모바일 앱 시안입니다. 저장소에는 현재 화면 구성을 보여주는 [HTML 시안](public/prototype/index.html)과 React Native·Expo 앱 시작 틀이 함께 있습니다. 화면별 목적과 표시 규칙은 [모바일 화면 기획서](docs/HeoNey/봉화지기_모바일_화면_기획서.md)에 정리되어 있습니다.

평상시에는 **홈과 프로필**을 중심으로 현재 지역의 정보와 사전 설정을 확인합니다. 재난 알림을 열거나 홈에서 활성 재난 안내를 선택하면 **긴급 대응 화면으로 바로 진입**하고, 재난별 기본 수칙은 그 화면에서 필요할 때 확인합니다. 긴급 상황에서 경보·영향 지역·현재 상태·행동요령을 한 화면의 흐름으로 빠르게 훑고 화면 전환을 최소화하도록 정보 순서와 버튼 배치를 설계했습니다.

## 모바일 화면 한눈에 보기

| 화면 | 주요 내용 | 이동 |
| --- | --- | --- |
| 홈 | 지도와 현재 위치 → **오늘의 행동요령** → **나의 사전준비** → **주변 재난 사항** | 상단 `프로필`로 사전 정보 화면 이동 |
| 긴급 대응 | 재난 경보 → 영향 지역 2D 지도 → 실시간 음성 대화 → 내 현재 상태 → 맞춤 행동요령 | 하단 `기본 수칙`, `대피로`, `119 신고` 영역 |
| 프로필 | 이름·연령대, 이동·의사소통 정보, 함께 대피할 대상, 선택 의료 정보 등 사전 입력 항목 | 뒤로 가기로 홈 복귀 |
| 재난별 기본 수칙 | 해당 재난에 공통으로 적용되는 기본 행동수칙과 피해야 할 행동·장소 | 뒤로 가기로 긴급 대응 복귀 |

`나의 사전준비`는 프로필과 재난 상황을 고려해 미리 챙기거나 점검할 일을 **최대 2개** 보여주는 기획입니다. 현재 HTML에는 비상가방과 이동 보조기구 점검이라는 고정 예시만 있습니다. `주변 재난 사항`의 목표는 조회 시점 기준 **3개월 이내 최신 3건**입니다. HTML의 목록 3개는 고정 예시이며 실제 기간 필터는 동작하지 않습니다.

긴급 대응의 **맞춤 행동요령**은 개인 상태에 따른 안내이고, **재난별 기본 수칙**은 국가 등 공식 기관이 제공하는 재난 공통 안내입니다. 현재 시안의 지역·재난·시간·프로필·행동 문구는 배치 예시입니다. 실제 안내 문구와 대응 판단은 서버 및 공식 출처 확인이 필요합니다.

## 화면 시안 확인

브라우저에서 [public/prototype/index.html](public/prototype/index.html)을 열면 로딩 화면 뒤 약 2.6초 후 첫 설정 화면이 보입니다. 여기서 이용 동의 항목을 확인하고 아래로 스크롤해 내 정보를 입력하는 모습을 볼 수 있습니다. `저장`을 누르면 기존 홈으로 이동합니다. 로딩 화면을 계속 보려면 주소 끝에 `#loading`을 붙이세요. `#onboarding`, `#home`, `#emergency`, `#profile`, `#rules`를 붙이면 해당 화면으로 바로 들어갑니다. 홈의 `프로필`과 긴급 대응의 `기본 수칙`은 시안 안에서도 이동할 수 있습니다.

HTML 시안은 **정적 화면**입니다. 첫 설정에서 선택한 동의와 입력 정보는 저장되지 않으며 실제 약관 고지나 기기 위치 권한 허용이 이루어지지 않습니다. 프로필 저장, 개인별 준비사항 추천, 실제 재난 수신, 재난 발생만으로 자동 화면 전환, 지도·음성 기능·119 발신이 동작함을 의미하지 않습니다. 시안에 남아 있는 별도 `3D 대피로` 임시 화면은 과거 자료이며 현재 MVP는 **2D 지도와 경로**를 사용합니다.

## Expo 앱 실행

Node **24 LTS (24.3 이상, 25 미만)**를 사용합니다. `.env`가 이미 있으면 복사 명령은 건너뜁니다.

```sh
npm ci
cp .env.example .env
npm run start:go
```

Expo 앱은 서버·지도 키 없이 **모의 데이터 모드**로 실행할 수 있습니다. 현재 Expo 화면은 HTML 시안과 별도로 개발 중인 기능 시작 틀이므로 화면 구성과 문구가 같지 않을 수 있습니다. 웹 미리보기는 `npm run web`이며, 실제 네이버 지도·푸시·백그라운드 위치는 개발용 앱 빌드에서 검증해야 합니다.

```sh
npm run check
```
