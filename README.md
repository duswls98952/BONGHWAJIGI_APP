# 봉화지기 Android 앱

산불 공식 경보와 서버가 갱신하는 개인별 대응 안내를 확인하는 내부 시연 앱입니다. 완성 HTML 목업을 바탕으로 Expo 화면을 구현하고 현재 `0.2.0-mvp` API에 연결했습니다. 단계는 **1 경고 · 2 대피 · 3 위급**이며 앱은 서버가 정한 단계와 행동을 표시합니다.

## 실행

Node24 (24.3 이상, 25 미만)를 사용합니다. 기존 `.env`가 있으면 덮어쓰지 않습니다.

```sh
npm ci
cp .env.example .env
npm run web
npm run check
```

기본은 합성 응답을 재생하는 mock 모드입니다. 웹의 `/prototype/`는 디자인 참고용 HTML이고 `/`는 실제 앱 구현입니다. LIVE는 설치 계정·세션 갱신·프로필/위치/현재 상태 쓰기·공식 경보·개인 정책 갱신을 실제 API로 처리합니다. 웹 세션은 메모리, Android 세션은 SecureStore에 보관합니다.

## 구현 범위

| 화면 | 연결된 기능 |
| --- | --- |
| 온보딩 | 시연 안내·동의, 설치 계정 생성, 프로필 저장 |
| 홈 | 공식 경보 원문, 기본 행동, 개인 준비 카드, 최근 산불 목록 |
| 내정보 | 프로필 수정·삭제, 현재 위치 공유/삭제, 알림 설정, 로그아웃 |
| 긴급 대응 | 서버3단계, 현재 상태 저장·재평가, 최신 행동과 단말 TTS |
| 기본 수칙 | 서버 지침·회피 항목·출처 |
| 대피로·119 | 2D 도식과 경로 미제공 안내, 사용자 확인용 신고 초안·단말 연결 버튼 |

Firebase와 지도 Client ID는 준비 전입니다. 실제 원격 푸시·지도 타일·검증된 도로 경로를 제공한다고 표시하지 않습니다. 실제 예측 모델 연결은 이번 범위에서 제외됐으며 확률은 unavailable/null입니다. 실제119 연락은 시험하지 않습니다.
