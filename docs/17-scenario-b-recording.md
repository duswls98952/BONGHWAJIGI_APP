# B 시나리오 실기기 촬영

2026-11-01 KST. [A 완성영상](16-scenario-a-final-and-b-recording.md) 전달 후, 같은 실기기에서 B의 보조기구 사용 프로필과 실제 서버 경보·대화·상태 반영을 촬영했다. 앱·실서버 통합 검증의 인수 자료이며 앱 소스는 변경하지 않았다.

## 촬영 파일

`artifacts/recordings/2026-11-01-B/B-scenario-01-raw.mp4`

- 원본 길이 262.891367초, 57,166,283bytes.
- H.264 1080×2400 가변 프레임, AAC 48kHz stereo.
- 사용자가 직접 선택·스크롤·음성 답변·상태 확인을 진행했다. 에이전트는 UI를 대신 선택하지 않았다.
- 화면과 앱 출력 음성을 녹음했다. 사용자 발화 원음이나 별도 마이크 소리는 녹음하지 않았다. 실제 음성 인식 결과는 화면에 표시된다.
- 대기 구간이 포함된 원본이며, A/B 합성이나 B 완성 편집은 아직 하지 않았다. 기존 A 모든 원본과 완성본을 보존했다.

## 실서버 준비와 검증

기존 A 촬영 파일을 보존하고, 같은 비공개 서버 폴더에 별도 B 준비 파일을 권한 600으로 만들었다. 계정 인증은 같은 단말용 계정을 재사용했다. 지역 근거를 분석 큐·임베딩·검색에 통과시키고 B의 합성 위치와 통행 가능한 참고 경로를 준비했다. 프로필을 자동 설정하거나 음성 답변·확인을 대신 수행하는 `prepare/register_roles/verify`는 실행하지 않았다.

A의 과거 아이 동반 상태 revision 1은 이미 만료됐으므로 보존했다. B 촬영 전 프로필은 빈 상태였고, 사용자가 직접 저장한 뒤 revision 7의 `walking_aid`, 보조기구 사용, 보호 대상 없음을 확인했다. 준비 전후 기존 A 파일과 현재 상태가 보존됐음을 검증했다.

경보를 한 번 입력했다. 긴급 큐 처리 후 공식 경보가 1.559초 만에 노출됐으며, 이어 분석 큐와 실제 Qwen 사건 통합이 완료됐다. 정책 revision 27은 대피 2단계였고 질문은 “보조기구를 사용해 혼자 이동할 수 있나요?”였다.

사용자가 실제 음성 답변을 보내고 제안을 확인한 뒤 현재 상태 revision이 1→2로 증가했다. 서버의 실제 처리 방식은 `qwen_grounded`, 완료·오류 없음이었다. `can_move=true`, `alone_now=yes`, `helper_present=false`를 확인했다. `child_present`는 미확인 null이며 A의 과거 아이 동반이 이어지지 않았다.

정책 revision 28에서 대피 2단계를 유지했고, 보조기구를 챙겨 이동하는 행동이 포함됐다. 어린이 행동은 없었다. 참고 경로 geometry와 정책 입력 revision이 일치했으며, 녹화 검증 시점에는 위치·경로·현재 상태가 유효했다. 합성 위치와 현재 상태는 기본 유효기간을 지키므로 재생 촬영 시 다시 준비해야 한다.

## 사용자 확인과 영상 검사

사용자는 다음 장면을 확인했다.

1. 보조기구 사용·보호 대상 없음 선택 및 저장.
2. 공통 비상가방·이동 보조기구 점검 두 준비 카드.
3. 새 공식 경보, 대피 2단계, 보조기구 질문과 읽어주기.
4. 실제 말하기·보내기 후 혼자 있음·이동 가능 제안과 명시적 상태 반영.
5. 현재 상태·맞춤 행동요령과 참고 경로.

CUA에서도 준비 카드, 질문 재생, 제안, 확정된 상태 태그와 맞춤 행동을 확인했다. 녹화 종료 직전 CUA 화면은 상태·행동요령이었다. 원본 마지막 실제 프레임을 별도로 검사하니 지도와 확정된 대화 화면이 담겨 있었다. 대피 2단계 헤더는 원본 125.973초와 226.043–231.996초, 경로선은 218.760–223.209초에서 확인했다. 촬영 직전·직후 관찰 화면과 원본 프레임을 구분한다.

원본의 프레임별 장면과 음성 구간·해시·전체 디코드 결과는 [검증 기록](validation/scenario-b-recording.json)에 기록한다. 녹화는 정상 종료됐고 남은 녹화 프로세스가 없다. 영상은 Git 제외 로컬 폴더에만 보관하며 실제 GPS·119 연락·외부 업로드는 수행하지 않았다.
