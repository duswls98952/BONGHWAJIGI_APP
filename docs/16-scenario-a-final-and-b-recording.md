기존 질문 TTS는 64.7초, 제안 안내 TTS는 78.9초에 유지된다. 사용자 발화 원음은 본편에 녹음되지 않았으며, 인식된 문장과 사용자 확인 장면이 화면에 담긴다. 마이크 보충 원본에는 일부 클리핑이 있었지만 최종 믹스의 피크는 -3.04dB이며 추가 클리핑은 검출되지 않았다.

## B 촬영 준비

사용자는 휴대폰 잠금을 풀고 홈에 놓았고 USB 개발 연결도 확인됐다. 서버 연결을 복원해 A의 과거 상태, 위치와 경로의 만료 여부를 읽기 전용으로 확인했다. A의 아이 동반 기록은 만료됐으므로 지우거나 상태 revision을 낮출 필요가 없다.

B는 사용자가 직접 보조기구 사용을 선택·저장하는 장면부터 촬영한다. 별도 B 촬영 상태 파일에 기존 단말 계정을 연결하고 합성 위치·사용 가능한 참고 경로·지역 근거를 새로 준비한다. 기존 A 준비 파일을 덮어쓰거나, 음성 답변·확인을 자동으로 실행하는 `verify`를 사용하지 않는다. 준비 명령이 프로필을 미리 선택하지 않도록 분리한다.

예정 순서: 보조기구 선택 → 공통/이동 보조기구 준비 카드 → 새 경보·대피 2단계 → 혼자 이동 가능한지 질문 → 실제 사용자 답변·확인 → 혼자 있음·이동 가능·맞춤 안내. B 실촬영과 서버 준비 변경은 후속 작업에서 기록한다.
