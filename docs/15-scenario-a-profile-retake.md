# A 프로필 직접 선택 재촬영

2026-11-01 KST. 사용자가 기존 A 확인본의 앞 9초를 제외하고, 이동과 의사소통 항목을 직접 스크롤·선택하는 장면을 새로 촬영하도록 요청했다. 기존 A 영상은 오프닝이나 두 화면 분할 편집이 들어가지 않은 A 단독 시나리오 소재다.

## 기존 영상의 앞 9초 제외

- 입력: `artifacts/recordings/2026-11-01-A/A-scenario-review.mp4` — 88.7초.
- 출력: 같은 폴더의 `A-scenario-after-9s.mp4` — 정확히 `[9.000, 88.700)` 구간, 79.7초.
- 기존 첫 프로필 컷은 10초이므로, 사용자가 지정한 9초만 제외한 파일에는 기존 프로필 장면이 처음 1초 남는다. 임의로 10초를 제거하지 않았다.
- 원본과 기존 확인본을 보존했다. 1080×2400 H.264 30fps / AAC 48kHz stereo / faststart. 전체 디코드, 첫 프레임의 9초 경계, 질문·제안 음성 시점 유지 검증을 통과했다.
- 자세한 편집 기록은 같은 폴더의 `after-9s-edit.json`에 있다.

파일은 모두 `artifacts/recordings/2026-11-01-A/`에 있다. 첫 두 테이크를 덮어쓰거나 삭제하지 않았다. 실제 화면 녹화의 앱 출력 오디오를 사용했으며 주변 마이크는 녹음하지 않았다.

사용자가 직접 내정보 진입, 기본 정보 입력, 이동 능력·계단·선호 안내·지원 여부·어린이·조력자 선택, 저장을 진행했다. 에이전트는 화면을 클릭하거나 항목을 대신 선택하지 않았다. 세 번째 녹화에서 선택 전·후 변화와 `저장했어요.` 완료 표시를 확인했다. 이번 녹화에는 이름·연령대 입력도 포함돼 있으므로 파일은 로컬에만 보관하고 외부 업로드하지 않았다.

새 촬영본과 앞 9초 제외본은 별도 파일이다. 이번 요청에서는 두 파일을 붙이거나 남은 프로필 1초를 추가로 제거하지 않았다. 오프닝·두 화면 분할·B 촬영도 수행하지 않았다.

## 연결과 검증

최초 USB 상태가 미허용이어서 사용자가 USB 디버깅을 허용했다. 각 테이크는 사용자의 준비 응답 뒤 시작하고 재촬영 또는 완료 응답 직후 정상 종료했다. 녹화 프로세스가 남아 있지 않음을 확인했다. 원본 가변 프레임 영상을 기본 null 출력으로 검사할 때 나타난 시간 기준 경고는 passthrough 검사와 30fps 전달본 검사로 구분했다.

파일 정보·해시·검증 결과는 [재촬영 검증 기록](validation/scenario-a-profile-retake.json)에 보관한다. 영상과 편집 JSON은 Git 제외된 로컬 폴더에 있으며, 작업 이력과 문서만 커밋한다.
