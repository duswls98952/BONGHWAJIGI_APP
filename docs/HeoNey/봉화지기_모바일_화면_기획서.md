# 봉화지기 모바일 화면 기획서

수정일: 2026-10-31
기준 시안: [모바일 HTML 시안](../../public/prototype/index.html)

## 기획 기준

이 문서는 현재 HTML 시안과 이후 사용자가 요청한 수정을 기준으로 화면 구성과 표시 규칙을 정리한다. 시안의 지역·재난·날짜·프로필·행동 문구는 배치를 보여주는 예시이며 실제 데이터의 기본값이 아니다. 화면 기획, 정적 HTML 시안, Expo 앱의 구현 상태는 서로 구분한다.

현재 모바일 MVP의 지도와 대피 경로는 **2D**다. 재난별 기본 행동수칙은 국가 등 공식 기관이 제공하는 재난 공통 안내이며, 긴급 대응 화면의 맞춤 행동요령은 개인의 현재 상태를 반영한 별도 안내다. 재난 대응 레벨·이유·행동·대화 문구는 서버가 제공하고 앱은 이를 표시한다.

평상시에는 홈과 프로필에서 지역 정보와 사전 설정을 확인한다. 재난 알림을 열거나 홈의 활성 재난 안내를 선택하면 긴급 대응으로 바로 진입하고, 재난별 기본 수칙은 긴급 대응에서 필요할 때 연다. 긴급 상황에서 경보·영향 지역·현재 상태·맞춤 행동요령을 한 화면의 흐름으로 빠르게 파악하고 화면 전환을 최소화하도록 정보 순서와 하단 행동 버튼을 구성한다. 이는 화면 설계 의도이며, 현재 HTML 시안은 재난 발생에 따른 자동 화면 전환을 구현하지 않는다.

현재 HTML 시안의 브랜드명은 대한민국정부상징체 R을 브라우저에서 굵게 합성한 미리보기다. 공식 Bold 파일은 없으며, 이 적용은 로고 글꼴 비교용 시안이다. 홈의 글자 안에는 참고 색상표의 정부청색 `#003764`와 정부적색 `#e4032e`가 정적으로 섞인 색 채움을 사용한다. 로딩 화면에서는 두 색의 원형 문양이 글씨를 감싸고 글씨 안에서만 두 색이 움직이며, 움직임 줄이기 설정에서는 정적인 색으로 표시한다. 나머지 화면 글꼴은 기기 기본 글꼴을 사용한다. 보조 설명, 목록의 시각·종료 표시, 미선택 태그, 입력 도움말, 지도 지명 등 회색 글씨는 검은색으로 표시한다. 경보의 빨간색, 선택·음성 안내의 파란색, 119 버튼의 흰 글씨처럼 의미가 있는 색상은 유지한다.

### 브랜드 참고 이미지

- [정부청색·정부적색 색상표](assert/정부상징_색상_참고.png): 사용자가 보내준 색상표의 RGB·CMYK·PANTONE 수치와 색상으로 다시 만든 참고 이미지다. [편집 가능한 SVG](assert/정부상징_색상_참고.svg)도 함께 보관한다. 첨부 사진의 원본 파일을 복사한 것은 아니다.
- [정부상징 원형 문양](assert/정부상징_원형문양_참고.png): [국립중앙과학관 MI 소개](https://www.science.go.kr/mps/cntnts/1135/moveCntnts.do)에 게시된 정부상징 문양 PNG 원본이다. 현재 HTML 로딩 화면의 문양은 이 원본을 참고해 별도로 그린 시안이다.

| 화면 | 진입과 역할 |
| --- | --- |
| 로딩 | HTML 시안을 처음 열면 흰 배경 중앙에서 정부청색·정부적색의 원형 문양이 큰 `봉화 지기` 글자를 감싼다. 문양은 고정하고 글자 안의 두 색만 일렁이게 한다. 시연을 위해 약 2.6초 후 홈으로 전환한다. `#home` 등 화면 주소로 직접 들어오면 로딩을 건너뛴다. 실제 서버 준비 상태를 나타내는 기능은 아직 아니다. |
| 홈 | 지도와 현재 위치, 오늘의 행동요령, 나의 사전준비, 주변 재난 사항 확인 |
| 긴급 대응 | 재난 경보, 영향 지역, 음성 대화, 현재 상태, 맞춤 행동요령 확인 |
| 프로필 | 홈의 `프로필`에서 진입해 사전 정보 입력, 뒤로 가기로 홈 복귀 |
| 재난별 기본 수칙 | 긴급 대응의 `기본 수칙`에서 해당 재난의 공식 기본 행동수칙 확인 |

HTML 시안에 남아 있는 별도 `3D 대피로` 임시 페이지는 과거 PNG의 배치 예시다. 현재 MVP 화면 목록에는 포함하지 않는다. 실제 대피 경로는 긴급 대응의 2D 지도에서 제공하는 방향으로 정리한다.

## 1. 홈

[홈 PNG](assert/01%20평상시%20홈.png)를 바탕으로 한 현재 시안의 표시 순서는 다음과 같다.

1. 상단 상태 표시줄부터 `봉화 지기` 이름과 톱니바퀴 아이콘을 앞에 둔 `프로필` 진입 링크까지 연한 푸른 회색 배경을 화면 양옆 끝까지 이어 표시한다. 이 색은 지도 주변과 아래쪽으로 점점 옅어져 `서울특별시 구로구 구로동` 위치 표시 줄이 시작되기 전에 흰 배경으로 돌아간다. 아이콘과 글씨는 함께 눌린다.
2. 별도 제목 없이 2D 지도와 내 위치로 본문을 시작한다. 위치 아이콘과 지역명은 지도 **아래**에 배치한다. 홈 시안에는 주변 소식 조회 반경 설정과 별도 GPS 버튼을 두지 않는다.
3. `오늘의 행동요령`은 연한 배경의 큰 카드 안에 제목과 카드형 안내를 표시한다. 큰 카드의 윗변은 제목이 있는 왼쪽만 높이고, 제목이 없는 오른쪽은 아래에서 시작하는 단차 형태다. 제목 옆 화살표나 별도 `나의 혜택` 영역은 두지 않는다. 두 안내 카드는 기존 세로 배치와 내용·아이콘을 유지하고, 외곽선 없이 연분홍색으로 채운다.
4. `나의 사전준비`도 `오늘의 행동요령`처럼 왼쪽 제목 탭과 낮은 오른쪽 윗변의 큰 카드 안에 표시한다. 준비 안내는 최대 2개 카드이며 아이콘 배치, 크기, 외곽선 없는 형태, 여백, 글자 스타일은 행동요령 카드와 맞춘다. 안쪽 카드의 배경은 참고 이미지의 `창업을 준비` 카드와 비슷한 연한 녹회색으로 구분한다. 현재 HTML 시안은 생수·손전등과 평소 쓰는 이동 보조기구 점검의 정적 예시이며, 실제 프로필에 따라 자동으로 바뀌지 않는다.
5. `주변 재난 사항` 제목 아래에 재난 목록을 표시한다. 각 행에는 재난명, 진행 상태, 시각, 간단한 상황 정보를 담는다. 이 목록에서 상세 화면으로 이동하는 버튼은 두지 않는다.

세 영역의 제목은 현재 시안에서 같은 크기와 서체를 쓴다. `주변 재난 사항` 제목과 목록 사이 간격은 `오늘의 행동요령` 제목과 카드 사이 간격에 맞춘다. 실제 맞춤 준비사항은 서버가 확인한 프로필과 재난 정보에 따라 제공해야 하며, 다리 통증만으로 휠체어 사용을 추정하지 않는다.

`오늘의 행동요령`과 `나의 사전준비` 카드 안의 픽토그램은 진한 회색으로 표시한다.

### 나의 사전준비 개인별 추천 사례

사용자가 직접 설정한 프로필 상태와 서버가 확인한 재난 상황을 바탕으로, 미리 챙기거나 점검할 사항을 최대 2개 카드로 보여주는 기획 예시다. 아래 조합은 확정된 추천 규칙이 아니며 현재 HTML 시안에서 자동으로 동작하지 않는다. 입력하지 않은 상태나 보조기구 종류를 앱이 추정하지 않는다.

| 설정한 상태 | 재난 상황 예시 | 표시할 준비 카드 예시 |
| --- | --- | --- |
| 이동 능력 `보조기구 사용`, 계단 이용 `어려움` | 침수 우려 | **이동 보조기구 점검** — 평소 사용하는 보조기구가 바로 사용 가능한지 확인하세요.<br>**비상가방 준비** — 생수와 손전등을 챙겨두세요. |
| 건강 및 의료 특이사항(선택)에 사용자가 `정기 복용약 있음`을 직접 입력 | 대설 예보 | **복용약 확인** — 평소 복용하는 약을 확인하고 챙겨두세요.<br>**충전기 준비** — 휴대전화 충전기나 보조배터리 상태를 확인하세요. |
| 함께 대피할 보호 대상 `어린이` | 산불 주의 | **어린이 비상용품 준비** — 아이에게 필요한 물, 간식, 여벌 옷을 비상가방에 챙겨두세요. |

물·손전등·복용약·충전기 등의 물품은 [국민안전24 비상대비용품](https://old.safekorea.go.kr/idsiSFK/neo/main_m/chk/emergencySupplies.html)과 [대설 행동요령](https://www.safekorea.go.kr/safekorea-kor/acts/nacts/action-guide.do?actsHeaderTitle=%EB%8C%80%EC%84%A4&category=heavySnow&menuSn=4)을 참고한 예시다. 표의 개인별 카드 문장은 공식 문구를 그대로 옮긴 것이 아니므로 실제 제공 전 출처와 적용 조건을 확인해야 한다.

### 주변 재난 사항 표시 규칙

**조회 시점을 기준으로 최근 3개월 이내의 주변 재난만 대상으로 하고, 그중 최신순으로 최대 3건만 표시한다.** 진행 중인 재난과 종료된 재난 모두 같은 기간·건수 규칙을 적용한다. 해당 기간에 3건보다 적으면 있는 항목만 표시하고, 3개월보다 오래된 항목으로 채우지 않는다. 재난의 시각과 상태는 제공 데이터에 따르며 화면에서 임의로 추정하지 않는다.

현재 HTML 시안은 3개 예시 행을 고정으로 보여준다. **3개월 필터와 최신순 선정이 동작하는 구현은 아니다.** 현재 Expo 홈 화면도 서버가 준 `feed.items`를 그대로 표시하므로, 이 규칙의 실제 적용 방식은 서버 응답 및 앱 연동에서 확인해야 한다. API 계약의 `feed.window_start`·`feed.window_end`와 항목 시각을 사용해 기간을 확인하되, 기준 시각이 없거나 불명확한 항목과 경계 시각 처리 방식은 서버와 맞춘다.

## 2. 긴급 대응

[긴급 대응 PNG](assert/02A%20긴급%20대응%20기본.png)를 바탕으로 한 현재 시안의 표시 순서는 다음과 같다.

1. 화면 상단의 시간·배터리 상태 표시부터 경보 영역까지 붉은 배경을 좌우 여백 없이 전체 너비로 잇고 빨간 테두리는 두지 않는다. 배경은 조금 더 진한 붉은색으로 약 1.1초 간격으로 깜빡이며, 움직임 줄이기 설정에서는 정지한다. 삼각형 느낌표 픽토그램과 크게 표시한 재난 경보 제목은 **가운데 정렬**하고 경보 영역 안에서 약간 위에 배치한다. 시안의 `홍수 대피 명령 발령`은 예시 문구다. 별도의 `심각` 문구는 표시하지 않는다. 실제 공식 경보와 개인 대응 레벨은 같은 값으로 취급하지 않는다.
2. `재난 영향 지역` 제목 아래에 2D 지도를 표시한다. 영향 지역은 지도 **중앙의 반투명 붉은 면**으로, 사용자 위치는 별도 위치 표시로 보여준다. 붉은 줄무늬와 `지도 샘플 · 실제 도로 아님`이라는 화면 문구는 시안에서 제거됐다.
3. `실시간 음성 대화` 제목, 중앙 파형, 현재 서버 발화 **한 개**를 윗변 전체가 같은 높이인 둥근 사각형 큰 카드에 담는다. 제목 옆 단차는 두지 않는다. 발화는 외곽선 없는 둥근 연파랑 카드에 보여주며 파형과 발화 글씨의 파란색 강조는 유지한다. 새 발화가 오면 이전 문구를 교체하며 채팅 이력은 쌓지 않는다. 시안의 질문 `지금 계신 곳에 물이 들어오고 있나요?`는 화면 예시이며 실제 발화 기본값이 아니다.
4. `내 현재 상태` 제목 아래에 현재 확인된 상태 태그를 표시한다. 프로필에 저장된 사전 정보와 재난 중 확인한 현재 상태를 구분한다.
5. `맞춤 행동요령` 제목 아래에 번호별 행동 전체를 `주변 재난 사항` 목록처럼 흰색 바탕과 연회색 선 테두리의 둥근 박스에 담아 표시한다. 설명용 도입 박스는 추가하지 않는다. 개인 상태에 따른 행동은 서버가 제공한다.
6. 하단 고정 영역에 `기본 수칙`, `대피로`, `119 신고`를 배치한다. `기본 수칙`은 재난별 공통 수칙으로 연결한다. MVP의 `대피로`는 2D 경로를 가리킨다. HTML의 119 버튼은 시각 요소이며 실제 신고·발신 기능을 입증하지 않는다.

`재난 영향 지역`, `실시간 음성 대화`, `내 현재 상태`, `맞춤 행동요령` 제목은 홈의 `오늘의 행동요령`과 같은 제목 스타일을 쓴다. 지도 아래 음성 대화, 음성 대화 아래 현재 상태, 현재 상태 아래 맞춤 행동요령의 구간 간격은 홈의 주변 재난 사항 위 간격에 맞춘다. 본문은 스크롤하고 긴급 행동 버튼은 하단에 유지한다.

시안의 영향 지역·위치·상태·행동은 모두 홍수 상황의 시각 예시다. 실제 영향 지역과 대피 경로는 검증된 서버 데이터로 표시해야 하며, 위치 또는 상태를 확인하지 못한 경우 안전하다고 단정하지 않는다.

## 3. 프로필

[프로필 PNG](assert/04%20프로필%20및%20설정.png)를 바탕으로 한 현재 시안은 상단 제목을 `프로필`로 표시한다. 왼쪽 뒤로 가기 버튼을 누르면 홈으로 돌아간다. 상단 이름·제목·첫 정보 박스 사이 간격은 현재 HTML 시안처럼 좁게 잡고, 선택되지 않은 태그의 글자도 읽기 쉽게 표시한다.

| 정보 묶음 | 현재 시안의 항목 |
| --- | --- |
| 기본 정보 | 이름 또는 호칭, 연령대 |
| 이동과 의사소통 | 이동 능력, 계단 이용 가능 여부, 선호 안내, 시각 지원 필요 여부, 청각 지원 필요 여부, 함께 대피할 보호 대상 |
| 추가 정보 | 건강 및 의료 특이사항(선택), 긴급 연락처, 주요 생활 장소, 건물 층수 |

프로필은 재난 전에 입력하는 정보다. 긴급 대응 화면의 `내 현재 상태`가 이를 참고할 수 있지만, 재난 중 대화로 확인되지 않은 상태를 현재 사실로 표시하지 않는다. HTML 시안의 선택 태그와 입력값은 화면 예시다. 저장·개인정보 처리·실제 서버 연동 완료를 의미하지 않는다.

## 4. 재난별 기본 행동수칙

[홍수 행동수칙 PNG](assert/05%20홍수%20행동수칙.png)를 바탕으로 한 현재 시안은 `홍수 행동수칙` 제목, `홍수 대비 기본수칙`, 번호별 수칙, `이런 행동과 장소는 피하세요` 순서다. 왼쪽 뒤로 가기 버튼은 긴급 대응 화면으로 돌아간다. 뒤로 가기 버튼과 제목의 간격·규격은 프로필 화면과 같고, 수칙 설명 및 피해야 할 장소의 글씨는 검은색이다.

이 화면의 목적은 **국가 등 공식 기관이 제공하는 재난별 기본 행동수칙**을 보여주는 것이다. 개인의 프로필이나 현재 상태에 맞춘 지침으로 해석하거나 긴급 대응 화면의 `맞춤 행동요령`과 섞지 않는다. 현재 HTML 시안에서는 `공식 안내 출처 · 확인 예정` 영역과 그 안내 문구를 삭제했다. 예시 수칙은 공식 검증 완료 문구가 아니므로 실제 제공 전 재난 종류에 맞는 공식 문구와 출처를 확인해야 한다.

## 구현·검증 상태와 남은 확인

| 항목 | 현재 상태 | 다음 확인 |
| --- | --- | --- |
| 화면 배치와 문구 | `public/prototype/index.html`에 정적 모바일 시안으로 반영 | 실제 기기에서 크기와 간격 확인 |
| 주변 재난 사항 | 시안에 예시 3행 표시. Expo 앱은 서버 `feed.items`를 그대로 표시 | 최근 3개월 이내·최신순 최대 3건 규칙을 실제 데이터로 검증 |
| 2D 지도·경로 | 시안의 지도와 영향 지역은 시각 예시 | 실제 지도·경로 데이터와 단말 동작 확인 |
| 음성·119 신고 | 시안에 파형·버튼 표시 | 실제 음성·신고 연동은 별도 검증 |
| 재난별 기본 수칙 | 홍수 예시 화면 표시, 출처 예정 안내 영역 삭제 | 공식 수칙의 문구·출처 검증 |

주변 재난 사항의 기간 경계와 항목 시각 기준은 API 제공자와 일치시켜야 한다. 규칙이 반영되면 3개월 이내 항목이 4건 이상일 때 최신 3건만, 1~2건일 때 해당 건만 보이고 기간 밖 항목은 보이지 않는지 확인한다.
