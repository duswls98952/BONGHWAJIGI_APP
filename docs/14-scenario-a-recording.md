- 모든 MP4의 영상·음성 스트림과 전체 디코드 성공을 확인했다. 해상도는 1080×2400이다.

- 사용자가 어린이 프로필·홈 카드·위급 화면·질문 재생·음성 인식·상태 반영·태그·행동요령을 직접 확인했다.

- 실제 GPS 공유·119 전화/문자·Firebase 발송·실제 예측 모델 연결은 수행하지 않았다.

## 촬영 중 조치

미러 창의 일부 터치와 스크롤이 안정적이지 않아 사용자에게 필요한 화면 이동과 발화를 요청하고 연속 녹화했다. 읽기 전용 미러 실행 설정을 일시 조정했으나 촬영 후 원래 실행 설정으로 복구했다. USB 연결이 미허용으로 전환된 뒤 사용자의 케이블 재연결·디버깅 허용으로 복구됐다. 녹화 프로세스는 모두 종료했다.

기존 A 준비 파일에는 `prepare/all/verify`를 재실행하지 않았다. 만료된 합성 위치·경로만 갱신하고 `trigger`로 경보 revision을 재발행했으며, 사용자의 실제 음성 답변과 명시 확인으로 상태를 저장했다. 다음 B 촬영은 B 역할·계정으로 별도 준비해야 한다.
