# 0.4.0 지역 행동요령과 A·B 개인 안내

2026-11-01 KST. 최신 사용자 요청에 따라 화면의 ‘시연’ 문구를 제거하고 지역 정보·사전 프로필·현재 상태를 분리했다. 내부 합성 여부, 출처 날짜, 참고 경로의 제한은 유지한다.

## 적용 내용

- 오늘의 행동요령은 서버 `today_guidance`를 사용한다. 위치와 지역 조건이 유효할 때 산림·건조 또는 확인된 안개 안내를 제공한다. 근거 없는 날씨를 생성하지 않는다.
- 나의 사전준비는 공통 카드 위, 개인 카드 아래 두 칸이다. 어린이 보호 대상과 이동 보조기구 등 프로필에 맞게 갱신한다.
- A의 사전 어린이 등록은 현재 동반을 뜻하지 않는다. 질문→답변→상태 반영 후만 아이 동반을 표시한다.
- B의 보조기구 사용은 이동불가를 뜻하지 않는다. 혼자 있음·이동 가능도 확인한 답변으로만 표시한다.
- 현재 서버 발화 하나만 보여준다. 전체 대화 이력과 사용자 발화 말풍선은 제거했다.
- 전경에서 새 관련 공식 경보를 받으면 배너와, 기존 OS 권한이 허용된 Android에서 로컬 알림을 요청한다. Firebase 원격 푸시는 아직 연결하지 않았다.
- A의 통제된 경로는 선을 숨긴다. B의 참고 경로에는 실제 통행 확인이 필요하다는 문구를 남긴다.

## 자료와 실제 연결

정부·기상청·지자체 공식 자료 6건과 2025년 전국 산불경보 기록을 사용한다. 개별 CBS 대피명령 전문은 확보하지 않았으므로 전국 경보를 개인 대피명령으로 바꾸지 않는다. A/B 위치·국소 위험·경로 상태는 별도 합성 입력이다. 자료 기준일은 그대로 보여준다.

웹 mock의 [A/B 캡처](api/mvp-filming-fixtures.json)는 테스트 API와 모델 stub의 응답이다. 실제 모델 검증은 별도 일반 서버의 큐·GPU Qwen 실행 기록으로 남긴다. 실제 예측 모델, GPS 측정, 119 연락은 이번 작업에 포함하지 않는다.

## 휴대폰 순서

운영자가 준비 단계로 역할과 지역 정보를 설정한다. 앱 홈에서 공통·개인 준비를 확인한 뒤 운영자가 경보를 입력한다. 새 공식 경보를 열어 현재 질문에 답하고 ‘상태 반영’을 누른다. A는 아이 동반·위급·통제 경로, B는 혼자 이동 가능·대피·참고 경로를 각각 확인한다.

합성 위치도 기본 유효기간 5분을 지킨다. 두 역할의 위치가 다르므로 운영자가 역할별 위치를 갱신한다. 휴대폰의 기본 안내 위치 버튼은 B 좌표이며 A 설정을 덮어쓸 수 있다.

## 검증

타입 검사와 78개 앱 테스트, 문서 링크 검사를 통과했다. 서버 실모델 파이프라인과 새 APK 검증 결과는 완료 후 이 절에 기록한다. 기존 0.3.1의 실제 한국어 음성 인식 검증은 [음성 수정 기록](12-demo-polish-voice-route.md)에 보존한다.

웹에서 A 아이 동반 확인·통제 경로 숨김, B 혼자 이동 확인·상태 태그·참고 경로를 확인했다. 초기 AppState 미확정과 A/B 모의 전환에서 상태 revision이 역행하던 문제를 수정했다. `npm run export:web`도 통과했다.
