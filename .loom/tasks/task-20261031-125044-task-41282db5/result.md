# 작업 결과

- 홈의 `오늘의 행동요령`과 `나의 사전준비` 카드 픽토그램을 진한 회색으로 바꿨다.
- 긴급 대응의 `실시간 음성 대화` 제목·파형·현재 AI 발화 한 개를 왼쪽 제목 탭과 낮은 오른쪽 윗변의 큰 카드에 담았다.
- 발화 박스의 외곽선을 없애고 둥근 연파랑 카드로 맞췄다. 발화 문구, 파형과 글씨의 파란색 강조는 유지했다. 모바일 화면 기획서도 갱신했다.

# 검증

- Safari에서 홈 픽토그램과 긴급 대응 음성 카드의 모양·색·문구를 확인했다.
- `npm run check:docs`와 `git diff --check`를 통과했다.

# 남은 위험과 다음 행동

- 정적 HTML 시안의 시각 변경이다. 실제 서버 발화 교체와 단말 TTS 동작은 이 변경으로 검증되지 않으며 별도 단말 검증 대상이다.
