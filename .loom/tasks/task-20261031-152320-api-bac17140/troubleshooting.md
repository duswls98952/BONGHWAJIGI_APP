# 점검 및 복구

초기 Loom 실행은 오래된 필수 브랜치 정책 때문에 중단됐다. 기존 develop이 main의 조상인 것을 확인하고 이력 손실 없이 앞으로 이동한 뒤 정책을 develop으로 맞춰 실행했다. 개발 서버는 샌드박스의 포트 접근 제한을 해소한 정상 실행에서 확인했다. 첫 브라우저 연결 거부 이후 준비된 서버의 새 탭으로 정상 확인했다.

휴대폰은 USB에는 보이나 개발 연결에는 없었다. 사용자에게 USB 디버깅을 요청해 승인 후 device 상태를 확인했다. 미해결 사항은 앱 구현과 서버 연동 자체이며 후속 Task 범위다.
