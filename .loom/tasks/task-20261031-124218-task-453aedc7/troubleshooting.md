# 문제와 처리

- Safari에서 홈으로 이동한 직후 이전 CSS가 표시됐다. 페이지를 새로고침해 변경된 CSS가 적용된 화면을 확인했다.
- `loom task validate`는 기존 PNG 기반 HTML 시안 Job과 새 참고 이미지의 연결이 약하다는 경고를 표시했다. 이번 변경은 같은 홈 HTML 시안의 후속 스타일 수정이며 Job의 화면 구현 범위 안에 있다. `loom validate --strict`는 통과했다.
- 구현을 막는 문제는 남지 않았다. 작업 전부터 수정돼 있던 이전 Loom 기록 파일은 변경하지 않았다.
