# 작업 결과

- 긴급 대응 화면의 `실시간 음성 대화` 큰 카드를 윗변 전체가 같은 높이인 둥근 사각형으로 바꿨다. 제목 오른쪽의 단차를 없앴다.
- 제목, 중앙 파형, 연파랑 발화 박스와 기존 문구·색상을 유지했다.
- 모바일 화면 기획서의 해당 카드 설명을 최신 시안에 맞게 수정했다.

## 검증

- Safari에서 긴급 대응 화면을 열어 카드 윗변, 제목, 파형, 발화 박스를 확인했다.
- `npm run check:docs` 통과: 문서 링크 12개 확인. `git diff --check` 통과.

## 남은 사항과 다음 행동

- 이번 작업은 정적 HTML 시안의 디자인 수정이다. 실제 서버 발화·TTS 연동은 앱 구현 및 단말에서 별도로 검증해야 한다.
- 관련 UI 구현 시 이 시안의 카드 형태를 적용하면 된다.
