# 작업 결과

- `맞춤 행동요령` 목록의 연회색 채움 배경을 제거하고, 홈의 `주변 재난 사항`과 같은 연회색 선 테두리의 둥근 박스로 바꿨다.
- 번호 배지는 원래의 연회색으로 돌리고 세 항목의 문구와 순서를 유지했다.
- 모바일 화면 기획서의 박스 설명을 사용자 의도에 맞게 수정했다.

## 검증

- Safari 긴급 대응 화면에서 흰 배경, 선 테두리, 세 항목과 번호를 확인했다.
- `npm run check:docs` 통과: 문서 링크 12개 확인. `git diff --check` 통과.

## 남은 사항과 다음 행동

- 정적 HTML 시안의 디자인 수정이다. Expo 앱에 적용할 때도 이 선 테두리 형태로 맞추면 된다.
