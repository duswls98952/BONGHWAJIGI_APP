# 작업 결과

- 홈 `봉화 지기` 글자에 사용자가 제공한 정부청색 `#003764`와 정부적색 `#e4032e`를 정적으로 적용했다.
- 로딩 화면 중앙의 글씨를 두 색의 원형 문양이 감싸도록 했다. 문양은 고정하고 글자 안의 두 색만 일렁이게 유지했다.
- 모바일 화면 기획서에 지정 색상과 로딩 문양을 반영했다. 기존 약 2.6초 후 홈 전환, 직접 해시 진입, 움직임 줄이기 동작은 유지했다.

## 검증

- Chrome 500px 화면 캡처에서 로딩 문양과 글씨의 중앙 배치, 중간 프레임의 색 이동, 홈의 정적 로고, 5초 후 홈 전환을 확인했다.
- `npm run check:docs` 통과: 문서 링크 12개. `git diff --check` 통과.

## 남은 사항과 다음 행동

- 원형 문양은 제공된 이미지의 색과 곡선을 참고해 HTML 안에 그린 시안이다. 최종 브랜드 원본 벡터를 받으면 해당 원본으로 교체할 수 있다. 실제 Expo 앱의 시작 화면은 별도 구현 대상이다.
