## 46. 홈 정적 태극색 로고와 시작 로딩 화면 추가

# 작업 결과

- 홈 `봉화 지기` 글자는 빨강과 파랑이 섞인 정적 채움으로 바꿨다.
- 시안을 주소 해시 없이 열면 흰 배경 중앙의 더 큰 글씨만 보이는 로딩 화면을 표시한다. 로딩 화면의 글자 색만 움직이고 약 2.6초 뒤 기존 홈으로 전환한다.

- 모바일 화면 기획서에 두 로고의 차이와 시연용 전환을 반영했다.

## 검증

- Chrome 모바일 크기에서 첫 로딩 화면, 로딩 색의 시작·중간 프레임, 홈 정적 로고를 확인했다.
- 5초 후 스크린샷과 DOM에서 로딩 화면이 숨겨지고 홈 화면이 보이는 것을 확인했다. `#profile` 직접 진입도 확인했다.
