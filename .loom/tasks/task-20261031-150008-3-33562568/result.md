# 작업 결과

- HTML 긴급 대응 화면 상단에서 `나의 대응 단계` 문구를 제거했다.
- 공통 경보 제목을 `산불 발생`으로 바꿔 `시연`과 `안내` 문구를 제거했다. 경고·대피·위급 원형 배지와 단계별 색상은 유지했다.
- 지도 이미지 대체 텍스트에서도 `시연용`이라는 표현을 빼고 예시 지도라고 설명했다.

## 검증

- `npm run check` 통과: 타입 검사, 테스트 14개, 문서 링크 검사.
- `git diff --check` 통과. HTML과 CSS에서 상단의 `나의 대응 단계`, `시연`, `산불 발생 안내` 문구가 제거된 것을 확인했다.
- 브라우저는 다른 조작과 겹쳐 이번 변경 후 캡처하지 못했다. 세 단계는 이전 작업에서 확인한 공통 HTML 화면과 해시 전환 코드를 그대로 사용한다.

## 남은 사항

- HTML 시안은 실제 경보 데이터와 연결되지 않는다. 화면 문구에서 시연 표시는 사용자의 최신 요청에 따라 제거했다.
