# 결정

- 사용자가 마지막 오프닝 촬영과 결합을 직접 요청했으므로 같은 앱 검증·영상 인수 Job의 후속 Task로 실행했다.
- 사용자 직접 조작을 녹화했다. 휴대폰 홈→앱 메뉴→봉화지기→앱 홈→내정보의 실제 장면을 사용한다. 화면 자동조작이나 앱·서버 기능 변경은 없다.
- 기존 105초 A/B revision2 완성본과 모든 촬영 원본을 보존한다. 오프닝의 긴 대기는 줄이고 중앙 화면에서 좌우 화면으로 이동·페이드하는 전환을 추가한다.
- 기존 본편의 다섯 음성 구간을 유지하고 오프닝 길이만큼 동일하게 이동한다. 추가 목소리·음악·알림음을 생성하지 않는다.
- 편집·검증 파일은 Git에서 제외된 로컬 artifacts 폴더에 저장하고 문서와 Loom 기록을 커밋한다. 외부 업로드는 하지 않는다.
