# 작업 결과

- `오늘의 행동요령` 큰 카드의 왼쪽 제목 부분만 위로 올라오고, 제목이 없는 오른쪽 윗변은 아래에서 시작하도록 바꿨다.
- 두 높이가 만나는 경계를 둥근 곡선으로 연결했다. 안쪽 카드의 세로 배치·색·문구는 유지했다.
- 모바일 화면 기획서에 상단 단차 형태를 기록했다.

# 검증

- Safari 홈 화면에서 새 CSS를 적용한 제목 영역과 오른쪽 낮은 윗변을 확인했다.
- `npm run check:docs`와 `git diff --check`를 통과했다.

# 남은 위험과 다음 행동

- 사진의 곡률을 픽셀 단위로 복제한 것은 아니며 현재 모바일 시안 폭에 맞춰 표현했다. 필요하면 시안을 보고 곡선 크기를 조정한다.
- 변경은 정적 HTML 시안에만 적용됐다.
