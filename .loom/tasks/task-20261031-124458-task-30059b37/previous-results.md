## 32. 오늘의 행동요령 참고 이미지 스타일 적용

# 작업 결과

- 홈의 `오늘의 행동요령` 제목과 기존 두 카드를 연한 배경의 둥근 영역으로 묶었다. 참고 이미지의 화살표와 `나의 혜택` 요소는 넣지 않았다.
- 행동요령 카드의 세로 배치·문구·아이콘을 유지하면서 외곽선을 제거하고 연분홍색 배경을 적용했다.
- 기존에 같은 카드 규격을 쓰는 `나의 사전준비` 두 카드에도 연분홍색 배경과 외곽선 제거를 적용했다. 모바일 화면 기획서도 갱신했다.

# 검증

- Safari 홈 화면을 새로고침해 제목 영역, 카드의 색과 테두리, 두 영역의 세로 배치를 확인했다.
- `npm run check:docs`와 `git diff --check`를 통과했다.

# 남은 위험과 다음 행동

- 참고 이미지는 사진이므로 색을 정확히 추출하는 대신 가까운 연분홍색을 시안에 적용했다. 색 조정이 필요하면 홈 시안을 보고 색상 값을 다시 지정한다.
- 정적 HTML 시안의 변경이며 Expo 앱은 별도 작업 대상이다.
