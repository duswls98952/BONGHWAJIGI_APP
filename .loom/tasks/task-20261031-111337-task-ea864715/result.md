# 작업 결과

- 모바일 화면 기획서의 `나의 사전준비` 아래에 개인별 추천 사례 3개를 추가했다.
- 보조기구 사용·계단 이용 어려움과 침수 우려, 정기 복용약과 대설 예보, 어린이와 함께 대피하는 상황의 산불 주의를 각각 프로필 설정·재난 상황·표시 카드로 연결했다.
- 사례별 카드는 최대 2개로 제한하고, 현재 HTML 시안의 고정 예시와 실제 서버 추천 기능을 구분했다. 참고한 국민안전24 비상용품·대설 안내 링크를 함께 기록했다.

## 검증

- 사례 3개와 문서 상대 링크를 확인했고 `git diff --check`가 통과했다.
- `npm run check:docs`는 수정하지 않은 `docs/HeoNey/모바일_화면_API_매칭_리스트.md`의 기존 `delivery/` 링크 오류로 실패했다.

## 남은 위험과 다음 행동

- 사례는 기획 문구이며 확정된 서버 추천 규칙이 아니다. 실제 서비스에서 프로필·재난 정보와 공식 출처에 맞는 추천 조건을 서버와 확정해야 한다.
