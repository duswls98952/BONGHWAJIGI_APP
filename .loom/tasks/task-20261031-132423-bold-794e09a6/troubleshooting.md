# 확인 과정

- 공식 내려받기 ZIP에는 Windows 설치 프로그램만 있었고, 그 안에서 `ROKG_R.ttf` 이름을 확인했다. 공식 Bold 파일은 발견되지 않았다. 원본 서체 파일을 공유한 자료에서 R 파일을 확보하고 내부 이름·글리프를 검사했다.
- 기본 샌드박스에서는 공식 사이트 DNS 조회와 Chrome 실행이 되지 않았다. 승인된 외부 네트워크 접근과 헤드리스 Chrome 실행으로 파일과 화면을 확인했다.
- 브라우저 UI 제어 호스트가 사용 불가해 화면 상호작용은 검증하지 않았다. 이번 변경은 홈 글꼴에만 한정된다.
