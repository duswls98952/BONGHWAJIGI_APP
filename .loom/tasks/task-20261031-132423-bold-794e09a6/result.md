# 작업 결과

- 홈 상단 `봉화 지기`에 대한민국정부상징체 R을 적용하고 CSS에서 굵게 표시했다. 공식 Bold 파일은 확인되지 않아 브라우저 합성 굵기를 사용한 시안이다.
- 원본 글꼴 파일은 수정하지 않고 출처·이용 조건을 `public/prototype/ROKG-SOURCE.txt`에 기록했다. 다른 화면의 글꼴은 유지했다.

## 검증

- 글꼴 내부 이름은 `ROKG R`, 굵기 값은 400이며 `봉`, `화`, `지`, `기` 글리프가 포함됨을 확인했다.
- Chrome 헤드리스 스크린샷에서 홈 상단 글씨가 새 서체로 표시되는 것을 확인했다.
- `npm run check:docs` 통과: 문서 링크 12개. `git diff --check` 통과.

## 남은 사항과 다음 행동

- 공식 Bold 서체는 없으므로 현재 모습은 합성 굵기다. 정부상징서체는 정부기관 명칭용으로 개발됐고 공공누리 제4유형이므로, 시안 밖의 상업 배포 전에 사용 적합성과 이용 허락을 확인해야 한다.
