# 작업 결과

- 긴급 대응 화면의 `맞춤 행동요령` 번호별 행동 세 항목을 하나의 연회색 둥근 박스 안에 배치했다.
- 번호 표시를 흰색 원형 배지로 유지해 회색 배경에서도 구분되게 했다. 항목 문구와 순서는 변경하지 않았다.
- 모바일 화면 기획서에 변경된 박스 형태를 반영했다.

## 검증

- Safari의 긴급 대응 화면 하단에서 회색 박스, 세 항목, 번호 배지를 확인했다.
- `npm run check:docs` 통과: 문서 링크 12개 확인. `git diff --check` 통과.

## 남은 사항과 다음 행동

- 이번 작업은 정적 HTML 시안의 스타일 변경이다. 실제 서버 제공 행동 목록의 표시와 단말 화면은 앱 구현 과정에서 별도로 확인해야 한다.
