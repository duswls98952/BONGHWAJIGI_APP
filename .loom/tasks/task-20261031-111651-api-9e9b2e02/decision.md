# 결정

- 현재 OpenAPI에 없는 사전준비 경로·필드를 문서에서 임의로 확정하지 않는다. `today_rules`와 긴급 `actions`도 준비 카드 데이터로 재사용하지 않는다.
- 완료된 2D MVP 기획을 기준으로 별도 S3 3D 화면을 매칭 목록에서 제외하고, 기존 `getRoute` URL과 `route_3d` capability의 차이를 명시한다.
- 진행 중 재난의 3개월 제한과 최대 3건은 현재 서버 계약에 보장이 없으므로 기획 목표와 계약 차이로 기록한다.
- 존재하지 않는 `delivery/` 참조를 현재 저장소의 문서 및 OpenAPI 사본으로 바꾼다. 개별 operationId는 깨진 링크 대신 식별자 텍스트로 남긴다.
