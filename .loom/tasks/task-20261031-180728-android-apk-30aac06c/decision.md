# 결정

기존 Naver2.9.1 Expo 플러그인과 사용자가 제공한 Client ID를 재사용한다. 실제GPS를 자동 수집하지 않고 기존 명시적 위치 공유 경로를 사용한다. 관련 지역 box를 화선·안전 구역·대피 경로로 표현하지 않는다. native 초기화 콜백과 타일 수신을 구분하고 인증 실패는 SDK 기본 토스트를 유지한다. 웹/Expo Go는 명시된 도식을 유지하며 Android0.2.1 내부 APK로 검증한다.

홈에는 사용자 공유 위치를 표시하고 사건의 붉은 영역은 해당 경보 상세에서 표시한다. 네이티브 타일·마커는 직접 캡처, 영역은 사용자 직접 확인과 서버 bounds 대조로 증거를 구분했다. 기존 0.2.0 배포 문서는 역사로 유지하고 docs/11을 최신 지도 APK 정본으로 추가했다.
