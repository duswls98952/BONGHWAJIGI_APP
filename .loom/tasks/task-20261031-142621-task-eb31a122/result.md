# 작업 결과

- 전체 동의 체크박스를 34px에서 26px로, 감싸는 카드의 최소 높이를 66px에서 56px로 줄였다.
- 두 필수·두 선택 동의 행의 최소 높이를 73px에서 54px로 줄여 항목 사이 간격을 좁혔다.

## 검증

- Chrome 모바일 너비 캡처에서 축소된 카드·체크박스와 네 동의 항목의 간격을 확인했다.
- 변경은 CSS 크기만이며 체크와 상세 열기 구조는 유지했다. `npm run check`(타입 검사, 테스트 14개, 문서 링크)와 `git diff --check` 통과.

## 남은 사항과 다음 행동

- 이번 변경은 정적 HTML 시안의 배치 조정이다. 실제 단말에서 터치 영역과 글자 가독성은 후속 확인할 수 있다.
