# 작업 결과

- 첫 설정 화면 제목을 `재난 대비용 상태설정`으로 바꾸고 해당 제목만 가운데 정렬했다.
- 모바일 화면 기획서의 첫 설정 설명도 새 제목과 배치에 맞췄다.

## 검증

- Chrome 모바일 너비 캡처에서 제목이 한 줄로 가운데 표시되는 것을 확인했다.
- 이전 제목 문자열이 HTML과 기획서에 남지 않은 것을 확인했다. `npm run check:docs`와 `git diff --check` 통과.

## 남은 사항과 다음 행동

- HTML 시안의 제목 표시 수정이다. 실제 앱 화면 적용은 별도 작업이다.
