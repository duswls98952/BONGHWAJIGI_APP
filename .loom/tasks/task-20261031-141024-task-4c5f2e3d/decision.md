# 주요 결정

- 참고 이미지의 금융 관련 항목 대신 봉화지기에 해당하는 서비스 이용약관, 개인정보 수집·이용, 개인위치정보 이용, 건강·의료 정보 처리만 목록에 넣었다. 위치와 건강·의료 항목은 선택으로 분리하고 `전체 동의` 자체에는 필수 표시를 붙이지 않았다.
- 첫 실행 화면의 프로필 필드는 기존 프로필의 항목을 그대로 재사용하되, 시안에 예시 사용자 값이 기본값으로 입력되지 않도록 비웠다.
- 미확정 법률 문안을 확정된 약관처럼 제시하지 않았다. 상세 열기에는 시안 수준의 짧은 설명을 두고, 저장·기기 권한 허용이 일어나지 않음을 명시했다.
