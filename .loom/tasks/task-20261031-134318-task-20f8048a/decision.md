# 결정

- CSS 배경 그라데이션만으로는 한글 획을 구분하기 어려워 기존 `ROKG_R.ttf`의 `봉`·`화` 윤곽을 분리한 SVG 경로를 사용했다. 글자 전체의 가독성과 기존 서체 형태를 유지한다.
- 참고 이미지의 `4`처럼 진한 파랑을 중심으로 주황 상단·빨강 가로획·하늘색 아래획을 배치했다. 기존 정부청색 `#003764`과 정부적색 `#e4032e`은 주색으로 유지했다.
- 글자 SVG는 장식으로 숨기고 `h1`의 `aria-label`로 `봉화 지기`를 읽도록 했다. 로딩 애니메이션은 일부 색상에만 적용하며 움직임 줄이기에서는 정지한다.
