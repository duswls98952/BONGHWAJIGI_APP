# 결정

사용자는 현재 APK를 앱 저장소 릴리스에 게시하도록 요청했고, 추가로 GPU 서버가 꺼져 있을 수 있으므로 앱만 올리라고 명시했다. 서버 상태 조회·재시작 없이 기존 0.4.0 APK를 게시한다.

검증된 APK 빌드 커밋 `74b4b65b95e2a59c2bc91518c2f677b11ce47b2c`가 원격 앱 저장소에 존재한다. 태그는 이 커밋을 가리키는 `v0.4.0-mvp`로 만들고 사설망·원격 푸시 미연결 조건을 설명한 prerelease로 게시한다. APK와 SHA256SUMS.txt만 첨부하며 로컬 빌드 보고서·키·계정 설정은 업로드하지 않는다.
