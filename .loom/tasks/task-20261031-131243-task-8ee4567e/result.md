# 작업 결과

- 긴급 대응의 `홍수 대피 명령 발령` 문구와 경고 아이콘을 상단 경보 영역 안에서 약 8px 위로 올렸다.
- 경보 배경을 더 붉은 두 색으로 조정하고 깜빡임 시간을 1.4초에서 1.1초로 줄였다.
- 모바일 화면 기획서에 색·속도·위치 변경을 반영했다. 기존 홈 화면은 추가하거나 변경하지 않았다.

## 검증

- Safari에서 긴급 대응 상단의 붉은 배경과 위로 이동한 경보 문구를 확인했다.
- `npm run check:docs` 통과: 문서 링크 12개 확인. `git diff --check` 통과.
- 움직임 줄이기 설정에서 `.emergency-banner` 애니메이션을 끄는 기존 규칙을 유지했다.

## 남은 사항과 다음 행동

- 로딩 화면과 첫 설정·개인정보 동의 화면은 계획 단계이며 이번 작업에서 만들지 않았다. 이후 두 화면만 기존 홈 앞에 추가하면 된다.
