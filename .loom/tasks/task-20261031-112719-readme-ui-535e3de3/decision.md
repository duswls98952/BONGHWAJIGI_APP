# 주요 결정

- 처음 읽는 사람이 화면부터 이해할 수 있도록 루트 README에서 실행 명령보다 홈·긴급 대응·프로필·재난별 기본 수칙을 앞세웠다.
- `docs/README.md`는 UI 문서와 개발 문서의 진입점으로 사용하고 상세 동작은 기존 기획서와 API 매칭 리스트에 연결했다.
- HTML은 고정 예시, Expo 앱은 개발 중인 기능 시작 틀이라고 명시했다. 실제 수신·지도·음성·발신 기능이나 개인화 추천이 동작하는 것으로 오해되지 않도록 했다.
- 현재 MVP는 2D 지도를 사용하므로 HTML에 남은 3D 임시 화면은 과거 자료로 설명했다.
