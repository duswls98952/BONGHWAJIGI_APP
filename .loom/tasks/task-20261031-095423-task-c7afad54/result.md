# 결과

긴급 대응 지도에서 붉은 재난 영향 지역의 위치 기준을 지도 중앙으로 옮겼다. 실시간 음성 대화 예시 문구를 `지금 계신 곳에 물이 들어오고 있나요?`로 교체했다.

홍수 행동수칙의 뒤로 가기 버튼과 제목은 프로필과 동일한 상단 간격·규격을 사용한다. 기본수칙의 설명과 피해야 할 장소 영역 글씨를 검은색으로 바꾸고, `공식 안내 출처 · 확인 예정` 영역과 아래 안내 문구를 삭제했다.

검증: HTML/CSS 선택자와 문구를 확인했고 `git diff --check`가 통과했다. 브라우저 제어 환경에서 `noWindowsAvailable` 오류가 발생해 화면 시각 검증은 수행하지 못했다.

남은 위험: 실제 브라우저와 모바일 기기에서 중앙 위치와 간격을 직접 확인하지 못했다. 다음 행동: HTML 시안의 긴급 대응과 홍수 행동수칙 화면을 열어 시각적으로 확인한다.
