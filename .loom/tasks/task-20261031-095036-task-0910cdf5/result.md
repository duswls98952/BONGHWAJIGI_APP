# 결과

`docs/HeoNey/봉화지기_모바일_화면_기획서.md`를 현재 모바일 HTML 시안과 최신 사용자 수정사항에 맞춰 다시 작성했다. 홈, 긴급 대응, 프로필, 재난별 기본 행동수칙의 화면 순서와 역할을 정리하고, 과거 기획의 3D 대피로를 현재 2D MVP 범위에서 분리했다.

홈의 최근 주변 재난 정보 규칙을 **조회 시점 기준 최근 3개월 이내 항목 중 최신순 최대 3건**으로 명시했다. 기간 내 항목이 3건 미만이면 있는 항목만 표시한다. 정적 시안의 3행과 실제 필터 구현을 구분했다.

검증: `git diff --check` 통과. 수정 문서의 링크 5개가 모두 존재함을 확인했다. `npm run check:docs`는 수정 문서가 아닌 `docs/HeoNey/모바일_화면_API_매칭_리스트.md`의 기존 깨진 링크 때문에 실패했다.

남은 위험: 3개월 경계와 항목 시각 기준은 API 제공자와 확정해야 하며 Expo 홈은 현재 서버 `feed.items`를 그대로 표시한다. 다음 행동: 서버 응답과 앱에서 최근 3개월·최대 3건 규칙을 실제 데이터로 검증한다.
