# 결정

사용자의 목업 동일화와 후속 대비/라운드 요청을 같은 UI 범위에서 적용했다. 탭형 카드는 연속 SVG 외곽으로 연결하고 기존 SVG 로고/서체를 재사용한다.

expo-speech-recognition 58.0.1로 단말 한국어 인식을 수행한다. 설치된 한국어 온디바이스 인식을 우선하고 기기 서비스 fallback 가능성을 고지한다. 앱은 오디오 파일을 저장하지 않고 인식 텍스트만 기존 인증 API로 전달한다.

대응 레벨 판단은 서버에 유지한다. Qwen 상태 제안은 실제 해석을 보여 준 뒤 확인하고, proposal_turn_id·본문·revision·만료를 서버에서 대조한다. 새 화면/계정에 늦은 요청을 적용하지 않는다.

경로는 서버가 제공하는 합성 좌표와 사건/위치 버전만 검증한다. 정책 전체 최신성 검사는 별도로 유지한다. 실제 안전 경로로 표현하지 않는다. 기존 내부 서명과 Tailnet API를 유지한다.
