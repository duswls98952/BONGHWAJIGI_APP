# 문제와 해결

- JSX View의 공백 텍스트 경고를 제거했다.
- fixture GeoJSON 배열의 TypeScript tuple 변환을 정정했다.
- 기존 route unavailable 테스트를 새 합성 경로·위치 삭제 계약으로 갱신했다.
- 경로 검증에 profile/state까지 요구해 실제 서버 경로가 숨겨지는 결함을 수정하고 회귀 테스트를 추가했다.
- 화면/계정 변경 중 위치 갱신 응답과 음성/대화의 늦은 결과를 폐기하도록 검토했다.
- 개발 HMR 이후 이전 모의 snapshot revision과 새 모듈 상태가 달라진 경우 오래된 요청은 거절됐고 새 세션에서 정상 제안을 확인했다.
- 서버 실제 Qwen의 선택적 후속 질문 생략은 상태 증거 검증을 유지하면서 서버에서 수용하도록 보완했다.
- 0.3.0에서 이미 허용한 마이크를 매번 requestPermissionsAsync로 다시 요청해 권한 Activity가 열리고 준비 세션이 즉시 취소됐다. getPermissionsAsync 선확인, 최초 요청 전 세션 미생성, 최초 허용 후 명시적 재시작으로 수정했다. 4개 권한 회귀를 추가했다.
- USB가 진단 중 끊겨 사용자에게 재연결을 요청했다. 재연결 후 0.3.1 설치를 완료했고 한국어 온디바이스 인식 시작/종료·제안 화면과 사용자의 상태 반영 성공을 확인했다.
- 기존 위급 상태는 계단 이용 어려움 제안만으로 임의 초기화하지 않는다. 단계 하향은 현재 상태를 명시적으로 수정하고 확인하는 계약을 유지한다.
