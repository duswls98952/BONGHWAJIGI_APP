# 문제와 해결

1. 샌드박스에서 로컬 HTTP 포트 바인딩이 `EPERM`으로 거부됐다. 승인된 실행 권한에서 Expo를 실행해 해결했다.
2. 포트를 사용할 수 있게 된 뒤 `metro`의 `./src/lib/TerminalReporter` export 오류가 나타났다. `expo` 51.0.39와 SDK 58 패키지의 버전 충돌이었다. `expo` 58.0.21 설치 후 서버가 시작됐다.
3. `npm run check`에서 TypeScript와 14개 테스트는 통과했으나, 문서 링크 단계는 `docs/HeoNey/`의 기존 상대 경로 때문에 실패했다. 관련 링크 정리는 후속 작업이다.
4. 컴퓨터 사용 브라우저 호스트가 연결되지 않아 화면의 시각 검사는 할 수 없었다. HTTP 응답과 웹 번들로 서버 동작을 검증했다.
