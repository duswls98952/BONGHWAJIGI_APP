# 결정

- 개발 문서의 화면 확인 경로인 `npm run web`을 사용하고, 외부 Expo 조회에 기대지 않도록 `EXPO_OFFLINE=1`을 설정했다.
- 현재 레포의 SDK 58 계열에 맞춰 핵심 `expo` 패키지를 58.0.21로 복구했다. 나머지 앱 화면과 API 동작은 변경하지 않았다.
- 로컬 포트 바인딩은 샌드박스에서 `EPERM`이 발생하므로 승인된 실행 권한으로 서버를 시작했다.
- `docs/HeoNey/` 링크 오류는 서버 기동과 별개인 기존 문서 문제로 기록하고, 이번 Task에서는 문서 자체를 고치지 않았다.
