# 작업 결과

- 첫 설정 화면의 텍스트 제목을 홈에서 쓰는 획별 색상 `봉화지기` 로고로 교체하고 가운데 배치했다.
- `개인위치정보 이용`의 화면 표시를 `[선택]`에서 `[필수]`로 바꾸고, 모바일 화면 기획서의 구분도 갱신했다.

## 검증

- Chrome 모바일 너비 캡처에서 로고 색상·중앙 배치와 위치정보 `[필수]` 표시를 확인했다.
- 이전 제목 및 위치정보 `[선택]` 표기가 HTML에 남지 않은 것을 확인했다. `npm run check:docs`, `git diff --check` 통과.

## 남은 사항과 다음 행동

- 현재 변경은 HTML 시안의 필수 표시이며 실제 동의 저장이나 기기 위치 권한 요청은 구현하지 않았다. 실제 서비스에서는 관련 고지와 권한 흐름을 확정해야 한다.
