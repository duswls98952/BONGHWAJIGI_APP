# 문제와 처리

- 샌드박스에서 로컬 HTTP 서버의 포트 바인딩이 `PermissionError`로 실패했다. 기존 HTML 파일을 Chrome의 `file://` 주소로 직접 열어 화면을 확인했다.
- Chrome 기기 도구의 임의 320px 너비 입력이 안정적으로 적용되지 않았다. iPhone SE 375px 프리셋으로 내정보 배치를 확인했고, 더 좁은 너비와 움직임 줄이기는 CSS 규칙을 확인했다.
- 작업 전부터 수정되어 있던 `.loom/tasks/task-20261031-120114-suite-bold-8ef87683/troubleshooting.md`는 건드리지 않고 이번 커밋에서 제외한다.
