# 구현 결정

- 사용자가 선택한 범위에 맞춰 긴급 대응 DOM을 복제하지 않고 한 화면을 세 해시에 연결했다. 단계별 변경은 상단 배경색과 원형 문구로 한정한다.
- 원형 단계는 개인 대응 수준으로 표시하고, 아래 산불 발생 안내는 `시연`을 붙여 실제 공식 대피 명령과 혼동하지 않도록 했다.
- 위급의 기존 붉은색 깜빡임만 유지하고 경고·대피 배너는 정적으로 둔다. 움직임 줄이기 설정은 위급 깜빡임을 중지한다.
- 내정보 저장은 시안용 안내만 표시하며 입력값을 브라우저 저장소나 서버에 보내지 않는다.
- 산불 기본수칙 문구는 국민안전24 산불 국민행동요령(https://www.safekorea.go.kr/safekorea-kor/acts/nacts/action-guide.do?category=forestFires&menuSn=4)의 안내 확인, 산에서 먼 경로, 이동이 어려울 때 도움 요청을 요약했다.
