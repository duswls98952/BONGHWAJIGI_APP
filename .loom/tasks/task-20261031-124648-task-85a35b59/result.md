# 작업 결과

- `나의 사전준비` 영역에 `오늘의 행동요령`과 같은 왼쪽 제목 탭, 낮은 오른쪽 윗변, 둥근 연결 곡선을 적용했다.
- 사전준비의 두 카드 배경을 참고 이미지의 `창업을 준비` 카드에 가까운 연한 녹회색으로 바꿨다. 행동요령의 분홍색과 두 영역의 내용·세로 배치는 유지했다.
- 모바일 화면 기획서에 두 영역의 모양과 색상 구분을 반영했다.

# 검증

- Safari 홈 화면에서 두 큰 카드의 모양과 분홍색·녹회색 구분을 확인했다.
- `npm run check:docs`와 `git diff --check`를 통과했다.

# 남은 위험과 다음 행동

- 사진 속 색은 촬영 환경의 영향을 받으므로 연한 녹회색을 시안에 근사해 적용했다. 색 조정이 필요하면 홈 시안을 보고 값을 조정한다.
- 정적 HTML 시안의 변경이며 Expo 앱은 별도 작업 대상이다.
