# 작업 결과

- 긴급 대응 경보의 붉은 배경을 상태바의 시간·배터리 영역부터 경보 문구까지 화면 전폭으로 확장했다.
- 경보의 빨간 테두리와 좌우 여백을 없애고 `홍수 대피 명령 발령` 글씨를 키웠다. 삼각형 픽토그램과 문구의 가운데 정렬, 깜빡임 효과를 유지했다.
- 모바일 화면 기획서의 경보 영역 설명을 갱신했다.

## 검증

- Safari에서 긴급 대응 상단의 연속 배경, 큰 문구, 테두리 제거를 확인했다. 홈의 상태바는 기존 흰색으로 표시됨을 확인했다.
- `npm run check:docs` 통과: 문서 링크 12개 확인. `git diff --check` 통과.

## 남은 사항과 다음 행동

- 정적 HTML 시안의 상단 표현이다. 실제 단말의 OS 상태바 색상 적용은 Expo 앱 구현 시 별도로 확인해야 한다.
