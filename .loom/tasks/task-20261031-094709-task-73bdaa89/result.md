# 결과

긴급 경보의 삼각형 느낌표를 Lucide의 Triangle Alert 픽토그램을 바탕으로 교체했다. 느낌표 점은 작은 크기에서도 보이도록 원형으로 만들고 아이콘을 24px로 키웠다. 지도에는 기존 반투명 붉은 영향 지역 면을 유지하고 빨간 줄무늬와 하단 `지도 샘플 · 실제 도로 아님` 문구를 제거했다.

아이콘 전용 연결 플러그인은 검색 결과 없어서 웹용 SVG를 시안에 포함하고 라이선스 고지를 추가했다.

검증: HTML/CSS 구조 검사와 `git diff --check`가 통과했다. Safari에서 선명한 느낌표, 붉은 면 유지, 줄무늬·문구 제거를 확인했다. `npm run check`의 타입 검사와 테스트 14개는 통과했으나 기존 `docs/HeoNey` 깨진 링크로 문서 검사가 실패했다.

남은 위험: 실제 모바일 기기에서는 확인하지 않았다. 다음 행동: 긴급 대응 시안에서 아이콘과 영향 지역 지도를 확인한다.
