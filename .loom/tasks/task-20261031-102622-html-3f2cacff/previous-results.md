## 20. 최신 홍수 시안에 맞춰 모바일 기획서 동기화

# 결과

모바일 화면 기획서의 긴급 대응과 홍수 행동수칙 설명을 직전 HTML 시안 수정에 맞췄다. 지도 중앙의 붉은 영향 지역, 새 음성 질문, 프로필과 같은 행동수칙 헤더, 검은 설명 글씨, 출처 예정 안내 영역 삭제를 반영했다.

## 21. 긴급 경보 배경에 붉은 맥동 효과 추가

# 결과

모바일 HTML 시안의 `홍수 대피 명령 발령` 경보 배경이 연한 붉은색과 조금 더 진한 붉은색 사이에서 1.4초 간격으로 부드럽게 반복 변화하도록 했다. 경보 글자색을 진하게 조정해 두 배경색에서 읽기 쉽게 유지했다. 동작 줄이기 설정에서는 경보 애니메이션을 끈다.

검증: PostCSS로 CSS를 파싱하고 경보·키프레임·동작 줄이기 규칙이 있는지 확인했다. `git diff --check` 통과. 브라우저 접근 호스트가 연결되지 않아 실제 화면의 동작은 확인하지 못했다.

남은 위험: 브라우저와 모바일 기기에서 점멸 체감 속도를 직접 확인하지 못했다. 다음 행동: 긴급 대응 시안에서 애니메이션을 보고 필요하면 속도와 붉은색 강도를 조정한다.
