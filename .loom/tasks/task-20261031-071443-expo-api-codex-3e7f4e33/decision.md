# 결정

- 초보 개발자와 한 컴퓨터의 순차 Codex 작업을 기준으로 Expo/React Native/TypeScript, Router, Query cache, 모의 모드를 선택했다.
- UI 이미지보다 최신 MVP 범위와 API 계약을 우선한다. 단계·확률·행동·발화는 서버 소유이며 앱의 자체 위험 판단을 금지한다.
- 기존 long poll과 voice-turns의 텍스트 계약을 재사용한다. full chat history/토큰 스트리밍을 임의로 추가하지 않는다.
- 2D는 네이버 지도를 우선 연결하되 시연 지역 품질과 실제 SDK는 기기 검증 대상이다. 기존 route의 경위도를 투영하고 route_3d를 임의로 route_2d로 해석하지 않는다.
- TTS는 현재 서버 발화의 단말 읽기로 구성한다. 화면 이탈·만료·백그라운드에서 중단한다.
- 백그라운드는 표시 푸시·복귀 동기화·동의 기반 위치 공유를 사용하며 영구 프로세스나 강제 볼륨을 보장하지 않는다.
- main에서 작업을 시작하려던 초기 Job 설정과 달리 Loom workspace 정책에 따라 실제 구현/완료 브랜치는 develop이다. 별도 동시 에이전트는 사용하지 않았다.
