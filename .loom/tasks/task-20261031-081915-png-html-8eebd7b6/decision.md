# 결정

- Expo 앱의 API와 네이티브 화면을 건드리지 않고 `public/prototype/`에 독립 시안을 두었다. PNG의 가상 재난·프로필 문구를 앱 실데이터 기본값으로 만들지 않기 위해서다.
- 화면에 없는 탭이나 미리보기 메뉴를 추가하지 않았다. 홈 설정 아이콘은 프로필로, 긴급 화면의 기본 수칙과 대피로 버튼은 각 PNG 화면으로 연결했다. 긴급 화면은 URL 해시로 직접 열 수 있다.
- 3D 페이지는 PNG의 임시 목업 표현만 재현했다. 실제 경로 계산이나 3D 렌더러는 추가하지 않았다.
- 119 버튼은 시각 요소로만 두어 시안에서 실제 긴급 전화를 시작하지 않도록 했다.
- 국가 제공 수칙을 위한 화면이라는 사용자 의도를 반영하되, PNG에 있는 `공식 안내 출처 · 확인 예정` 문구를 보존해 현재 예문을 검증 완료된 공식 지침으로 표현하지 않았다.
