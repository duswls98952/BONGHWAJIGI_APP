# 결과

`public/prototype/`에 다섯 PNG의 모바일 화면을 독립 HTML 시안으로 구성했다. 기본 주소는 `http://localhost:8081/prototype/index.html`이다. `#home`, `#emergency`, `#route`, `#profile`, `#rules`로 각 화면에 직접 접근할 수 있다.

홈은 위치·반경·지도·안전 카드·주변 재난 목록, 긴급 화면은 공식 경보·영향 지역·음성 파형·현재 상태·개인 맞춤 행동요령·하단 버튼, 3D 화면은 PNG의 준비 중 목업, 프로필은 PNG와 공통 UI 키트의 입력 항목, 홍수 행동수칙은 재난별 기본수칙과 출처 확인 예정 문구를 담았다. 긴급 화면의 맞춤 행동요령과 기본 수칙 화면의 공통 수칙을 분리했다.

검증: 개발 서버가 HTML·CSS·JavaScript·SVG 네 파일을 모두 HTTP 200으로 제공했다. 다섯 화면 ID와 내부 링크 대상, JavaScript 문법, SVG XML 파싱, `git diff --check`를 확인했다. 웹 export가 성공했고 네 파일이 `dist/prototype/`에 포함됐다. 브라우저 렌더링 호스트를 사용할 수 없어 픽셀 수준의 모바일 화면 시각 비교는 수행하지 못했다. 실제 서버·119 발신·3D 경로·공식 수칙 검증은 시안 범위에 포함하지 않았다.

다음 행동: 브라우저에서 각 주소를 열어 PNG와 여백·글꼴을 직접 비교하고 필요한 시각 조정을 반영한다.
