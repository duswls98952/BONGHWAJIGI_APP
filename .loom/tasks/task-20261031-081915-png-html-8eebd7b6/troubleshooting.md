# 검증 제한

Expo 서버의 정적 파일 제공과 웹 export는 성공했다. 자동 시각 검증에 사용할 브라우저는 연결되지 않았다. in-app 브라우저 호스트가 사용할 수 없는 상태였고, gstack Chromium 보조 실행은 설치 파일 불완전으로 시작되지 않았으며 Chrome 앱 제어도 시간 초과됐다. HTML 파일과 네 정적 파일은 정상 제공되므로 브라우저에서 직접 열어 시각 비교할 수 있다.

기존 `npm run check`의 문서 링크 단계 실패는 이전 Task에서 확인한 `docs/HeoNey/` 상대 경로 문제다. 이번 정적 HTML 변경은 TypeScript 앱 코드와 API 계약을 변경하지 않았다.
