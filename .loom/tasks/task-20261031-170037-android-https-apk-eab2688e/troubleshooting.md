# 문제와 조치

미러링 창 캡처/입력 오류가 반복돼 최종 단말 검증은 사용자 직접 터치와 서버 읽기 조회로 진행했다. 초기 경고 표시 보고만으로 성공 처리하지 않고 실제 단계 갱신 실패를 대조했다. 위치 버튼 메시지가 위쪽에만 있어 같은 카드 아래에도 진행·성공·오류를 표시했다.

HTTP422의 원인은 휴대폰 시계가 서버보다 약0.603초 앞선 상태에서 모든 미래 입력을 거절하던 서버 검사였다. 서버959ab56에서 위치/현재상태의 30초 이내 오차를 수신 시각으로 보정하고 5분 유효기간을 늘리지 않도록 했다. 104개 서버 테스트와 실서버 +0.6초 수용/+40초 거절을 확인했다. 단말 재시도 후 위치와 정책3단계 저장이 일치했다.

음성은 사용자가 한 차례 미확인으로 정정해 완료 처리를 보류했다. 단말 TTS 연결과 음량을 읽기 점검했고 사용자가 무음 해제 후 정상 청취를 최종 확인했다. 추가적인 엔진 교체나 단말 음량 강제 변경은 하지 않았다. 비밀번호·토큰·프로필 본문은 진단 로그에 기록하지 않았다.
